# 🎓 Millionaire Classroom

منصة تعليمية تفاعلية تحوّل حصة اللغة الإنجليزية إلى مسابقة "من سيربح المليون" — مصممة للسبورات الذكية والبروجكتور داخل الفصل.

**رابط التطبيق:** `_VERCEL_URL_`
**لوحة المعلم:** `_VERCEL_URL_/admin.html`

---

## ✨ المميزات

### للمعلم (admin.html)
- **رفع ملف الدرس** (PDF / Word / Text): يقرأ المحتوى الفعلي ويولّد أسئلة تغطّيه بالكامل، مع اقتراح اسم الدرس تلقائيًا
- **توليد الأسئلة بالذكاء الاصطناعي**: اكتب الصف والدرس فقط
- **استيراد Excel**: نموذج جاهز يُرفع بضغطة زر
- **تقرير تشخيص الأخطاء**: أكثر الأسئلة التي تعثر فيها الطلاب
- **إدارة كاملة**: إضافة وتعديل وحذف وتصفية الأسئلة

### للفصل (index.html)
- **سلم جوائز من 15 مستوى** مع نقاط أمان
- **وضع الفرق**: Team Blue 🔵 ضد Team Red 🔴
- **النطق الصوتي** (Text-to-Speech) بلكنة أمريكية واضحة
- **أسئلة بالصور** للمفردات
- **شرح بعد كل إجابة** لتحويل اللعبة لمراجعة فعلية
- **مؤثرات**: Confetti عند الفوز، Screen Shake عند الخطأ
- **وسائل المساعدة**: 50:50 وتصويت الفصل
- **مؤقت اختياري** قابل للتعطيل
- **التحكم بالكيبورد**: A/B/C/D للتثبيت، 1/2 للمساعدات، S للنطق، Enter للتالي
- **يعمل أوفلاين** — كاش محلي + مزامنة تلقائية عند عودة الإنترنت

## 🚀 خطوات التشغيل (5 دقائق)

### 1) Supabase — قاعدة البيانات المجانية
1. ادخل [supabase.com](https://supabase.com) وأنشئ مشروعًا جديدًا
2. من القائمة الجانبية: **SQL Editor** → **New query**
3. انسخ كامل محتوى ملف [`supabase/schema.sql`](supabase/schema.sql) والصقه → **Run**
4. من **Project Settings → API** انسخ:
   - `Project URL`
   - `anon public` key
   - `service_role` key

### 2) Gemini — مولّد الأسئلة
1. ادخل [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. أنشئ مفتاحًا جديدًا

### 3) Vercel — الاستضافة المجانية
1. ارفع هذا المستودع إلى GitHub (بدون ملف `.env`!)
2. ادخل [vercel.com](https://vercel.com) → **Add New Project** → اختر المستودع
3. من **Settings → Environment Variables** أضف:

| المتغير | القيمة |
|---|---|
| `VITE_SUPABASE_URL` | رابط المشروع من Supabase |
| `VITE_SUPABASE_ANON_KEY` | مفتاح anon public |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح service_role (سري — لا يصل للمتصفح) |
| `GEMINI_API_KEY` | مفتاح Gemini |
| `ADMIN_PASSWORD` | كلمة سر لوحة المعلم — اخترها بنفسك |

4. اضغط **Deploy** — وستحصل على الرابط خلال ثوانٍ

## 🔒 الأمان

- **لا توجد أسرار في الكود نهائيًا** — كلها في متغيرات بيئة Vercel
- مفتاح `service_role` **لا يصل للمتصفح** — يُستخدم فقط في دوال الخادم
- **Row Level Security** مفعّلة: القراءة عامة، الكتابة للخادم فقط
- لوحة المعلم محمية بكلمة سر تُتحقق منها كل دالة API
- مفتاح `anon` الموجود في المتصفح آمن بالتصميم — RLS هي الحارس الحقيقي
